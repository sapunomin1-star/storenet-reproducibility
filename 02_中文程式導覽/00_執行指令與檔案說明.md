| 位置 | 內容與用途 |

## 進階計算：從原始資料重新算

一般讀者使用 [操作步驟](01_Mac與Windows操作.md) 即可。以下適合要修改實驗、重算整個研究的人。MATLAB 指令在 Mac、Windows 相同，先把 Current Folder 切到專案最外層並執行 `addpath('StoreNet/src')`。下面的 RunId 可以在命令視窗改名，避免與自己的舊結果衝突。

**StoreNet 代表日改進策略：**

```matlab
run_bahloul_frontier_v1(Dates=datetime(2020,8,24), IntervalMinutes=30, RunId="rerun_frontier_typical", AnchorStrategies=["SH_BM","VPP_BM","VPP_BM_PEAK_LEX","PS","PSDT","LL"], BatteryEfficiencies=0.8469, ConfigOverrides=struct("maxSolverTimeSeconds",600), PersistFrontierSolutions=true);
summarize_bahloul_frontier_v1("StoreNet/results/bahloul_vpp_improvement_v2_frontier/rerun_frontier_typical", FormalTypicalMetricsPath="StoreNet/results/b2022_ir_v1_formal/b2022_typical_v1_20200824/typical_metrics.csv", PeakGuardMetricsPath="StoreNet/results/bahloul_vpp_improvement_v1/storenet_typical/strategy_metrics.csv");
```

輸出：`StoreNet/results/bahloul_vpp_improvement_v2_frontier/rerun_frontier_typical/`。

**StoreNet 每月代表日的改進策略：**

```matlab
days = reshape(datetime(2020, repelem(1:12,4), repmat([1 2 15 16],1,12)), [], 1);
run_bahloul_frontier_v1(Dates=days, IntervalMinutes=60, RunId="rerun_frontier_monthly", CapRatios=[2 1.5 1.25 1 0.9 0.8 0.7 0.6 0.5], DemandCharges=[0.05 0.1 0.2 0.5 1], ConfigOverrides=struct("maxSolverTimeSeconds",60));
summarize_bahloul_frontier_v1("StoreNet/results/bahloul_vpp_improvement_v2_frontier/rerun_frontier_monthly", FormalMonthlyMetricsPath="StoreNet/results/b2022_ir_v1_formal/b2022_monthly_v1_2020/daily_metrics.csv", PeakGuardMetricsPath="StoreNet/results/bahloul_vpp_improvement_v1/storenet_monthly/strategy_metrics.csv");
```

輸出：`StoreNet/results/bahloul_vpp_improvement_v2_frontier/rerun_frontier_monthly/`。重畫時把操作步驟中 `render_frontier_figures.py` 的 `--typical`、`--monthly` 輸入換成自己重算的資料夾。

**澳洲 52 戶外部驗證：**

```matlab
run_external_validation(SpecPath="StoreNet/config/crossenv/ausgrid_2012_2013_exclude_customer161_sensitivity.json", RunId="rerun_external_no161");
render_external_validation("StoreNet/results/rerun_external_no161");
```

輸出：`StoreNet/results/rerun_external_no161/`。
