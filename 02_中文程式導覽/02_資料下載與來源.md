# 資料下載與來源

[回首頁](../README.md) · [Mac／Windows 操作步驟](01_Mac與Windows操作.md)

**程式、報告和已算好的結果都在 GitHub；大型原始資料另外下載。** 首次使用最方便的方式，是按照操作步驟執行 `StoreNet/tools/download_data.py`，它會自動下載、檢查版本並放進正確資料夾。使用者不用處理完整性清單。

## 要下載哪些資料

| 你要做什麼 | 需要的資料 | 下載與放置 |
|---|---|---|
| 看報告、看已附的圖與 CSV | 不需原始資料 | [下載程式與報告 ZIP](https://github.com/sapunomin1-star/storenet-reproducibility/archive/refs/heads/main.zip) |
| 重算資料論文圖 5～9、方法論文、StoreNet 改進策略 | StoreNet Figshare v1，共 46 檔 | [StoreNet 資料包](https://github.com/sapunomin1-star/storenet-reproducibility/releases/download/v1.0.0/storenet-data-v1.zip)；解壓後把其中 `StoreNet/data/raw/` 合併到專案相同位置 |
| 重算圖 10 電壓不平衡 | StoreNet 資料及電網資料 | 下載程式會從已記錄的原始網址補齊電網；也可依下方電網小節手動取得 |
| 重算澳洲外部驗證 | Ausgrid 2012–2013 CSV | [Pierre Haessig 封存說明](https://pierreh.eu/ausgrid-solar-data/)／[封存 ZIP](https://pierreh.eu/downloads/Ausgrid_solar_home_data.zip) |

StoreNet 壓縮包約 156 MiB，解壓後約 1.0 GiB；Ausgrid 封存 ZIP 約 54 MiB。資料包不包含 Python 環境，環境在自己的電腦安裝。

## 手動下載與放置

### StoreNet

資料版本固定為 [Figshare collection v1](https://doi.org/10.6084/m9.figshare.c.6829134.v1)，包含 H1～H20 的 W／Wh 共 40 個 CSV、weather.csv、4 個作者 Python 程式及 README.md，共 46 檔。GitHub Release 是這 46 檔的原樣副本，保留原始檔名與內容；授權為 CC0。

解壓後應能看到 `StoreNet/data/raw/H1_W.csv`、`StoreNet/data/raw/H1_Wh.csv` 等檔案。避免多套一層 `raw/raw/` 或 `storenet-data-v1/StoreNet/`。

### Ausgrid

資料原作者是 Ausgrid，下載來源是 Pierre Haessig 在 2026 年提供的封存副本，授權 CC BY 3.0 Australia。原 ZIP 內有多個年度，本程式只使用 2012–2013。

- ZIP 保留在 `StoreNet/data/external/ausgrid/raw/Ausgrid_solar_home_data.zip`。
- 從 ZIP 解出 `Solar home 2012-2013.csv` 與 `Ausgrid solar home electricity data notes (Aug 2014).pdf`，放在 `StoreNet/data/external/ausgrid/raw/extracted/`。
- 不要用 Excel 另存後覆蓋原始 CSV；計算程式直接讀原始檔。

## 哪些檔案不用下載

`StoreNet/data/derived/figure10s_hourly_jan_jun.csv` 是圖 10 自動整理的每小時資料，首次執行會建立。`StoreNet/data/prep/storenet_30min.npz` 是舊版快速檢視用的半小時陣列，可由 `prep_30min.py` 產生；主要逐圖入口不需要它。

## 只下載其中一組

操作步驟的下載指令預設下載全部。需要時可在指令最後加上：

| 參數 | 用途 |
|---|---|
| `--dataset storenet` | 只取得 StoreNet 的 46 檔 |
| `--dataset ausgrid` | 只取得 Ausgrid |
| `--dataset grid` | 只取得電網 |
| `--source upstream` | StoreNet 改由 Figshare 逐檔下載；不使用 GitHub 資料包 |

無須手動核對長串驗證碼。下載程式只採用已記錄的版本，遇到同名但內容不同的現有檔案會提示先移開；不會直接覆蓋使用者修改過的資料。
